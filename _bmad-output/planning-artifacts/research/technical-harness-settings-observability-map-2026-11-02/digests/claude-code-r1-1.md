## Setting class x layer

Legend: M = managed (remote / MDM / file / HKCU), C = `--settings` or dedicated CLI flag, E = shell env var, L = `.claude/settings.local.json`, P = `.claude/settings.json`, U = `~/.claude/settings.json`, G = `~/.claude.json`, R = repo files other than settings.

| Setting class | Layers that can set it | Notes | Resolved view |
|---|---|---|---|
| Permission rules (allow/ask/deny) | M C L P U | union across scopes; deny>ask>allow; project allow waits for trust; `allowManagedPermissionRulesOnly` | `/permissions` (rules + source file) |
| Permission mode `defaultMode` | M C(`--permission-mode`) L P U | `auto`/`bypassPermissions` only from U, M, or flag; `disableAutoMode`/`disableBypassPermissionsMode` | `/status`; mode shown in UI |
| Auto mode `autoMode.*` | M C U (not P, not L) | additive across scopes; `$defaults` splice | `claude auto-mode config` (JSON, effective); `/permissions` Auto mode tab |
| Model / provider | M C(`--model`, `--settings`) E(ANTHROPIC_MODEL, CLAUDE_CODE_USE_BEDROCK/VERTEX) L P U | env beats file for ANTHROPIC_MODEL; flag beats env; managed `availableModels`/`deniedModels` lock | startup header names file for project/managed model; `/status` (unverified for model field) |

## Leads worth chasing

- Settings reference Scope column (https://code.claude.com/docs/en/settings-reference) for an authoritative per-key scope list, and "Variables Claude Code ignores in env".
- Statusline JSON input and hook input payloads (statusline and hooks docs): which effective fields they carry (model, context `used_percentage`, permission_mode).
- `claude mcp list` / `claude mcp get` output and MCP scope doc (https://code.claude.com/docs/en/mcp) for local vs user scope storage in `~/.claude.json`.
- server-managed-settings page: fetch and caching behavior, local cached copy location (2.1.314 mentions 'the local copy of your organization's server-managed settings').
- Issue #72634 (policyHelper output discarded in favor of remote payload) and #19369 (docs on CLI vs managed precedence, open).
- Whether #70181 behavior reproduces on 2.1.317 after 2.1.312/2.1.316 managed-fetch changes.
- `--setting-sources` flag semantics and 2.1.314 fix.

## Looked for, could not find

- A way to inspect fetched feature-flag values or the server-chosen cache TTL.
- Publish dates on docs pages (none shown).
- Maintainer responses on #89346 and #90408.
- Exact path of MDM-delivered plist on disk (doc gives only the preferences domain).
