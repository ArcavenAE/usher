## Setting class x layer

Layers: SYS = /etc/goose/config.yaml or %PROGRAMDATA% (source only); ADD = GOOSE_ADDITIONAL_CONFIG_FILES (source only); USR = user config.yaml; ENV = GOOSE_*/other env; FLAG = CLI flag; SESS = in-session slash command; DESK = Desktop Settings UI (writes USR); RCP = recipe; KR = keyring/secrets.yaml; PROJ = project files.

| Setting class | Layers that can set it | Resolved view |
|---|---|---|
| Permission mode | SYS, ADD, USR, ENV (GOOSE_MODE), SESS (/mode), DESK | goose info -v; /status |
| Per-tool permissions | permissions/tool_permissions.json, permission.yaml, DESK/CLI UI | none found beyond files |
| Model / provider | SYS, ADD, USR (active_provider/providers), ENV, FLAG (run --provider/--model), SESS (/model), RCP (subagent settings), DESK | goose info -v; /status |
| Secrets / API keys | ENV, KR (keyring or secrets.yaml); not USR | none (by design) |
| Context / compaction | USR, ENV (GOOSE_AUTO_COMPACT_*, GOOSE_CONTEXT_LIMIT), SESS (/compact) | goose info -v |
| Instructions | PROJ (.goosehints, AGENTS.md cwd up to repo root), global ~/.config/goose/ hint files, ENV (CONTEXT_FILE_NAMES, GOOSE_MOIM_*), RCP | none found |
| Recipes / skills | USR (slash_commands), ENV (GOOSE_RECIPE_PATH, GOOSE_RECIPE_GITHUB_REPO), FLAG (--recipe), SESS (/skills) | goose run --explain / --render-recipe |
| Extensions (MCP) | SYS, ADD, USR (extensions:, merged per entry), FLAG (--with-*), SESS (/extension, /builtin), DESK, RCP | goose info -v (enabled extensions) |
| Extension allowlist | USR/ENV GOOSE_ALLOWLIST (remote HTTPS URL) | effect-only (load refused) |
| Telemetry / OTEL | USR, ENV (GOOSE_TELEMETRY_ENABLED, OTEL_*, LANGFUSE_*), DESK privacy toggle, configure | goose info -v |
| Safety (adversary, prompt-injection) | ~/.config/goose/adversary.md, USR/ENV SECURITY_PROMPT_* | none found |
| Paths | ENV GOOSE_PATH_ROOT | goose info (paths) |
| Hooks | not found | n/a |
