## Setting class x layer

Layers: CLI = flags/-c; Proj = trusted project .codex/config.toml; Prof = ~/.codex/<name>.config.toml; User = ~/.codex/config.toml; CloudDef = cloud config defaults; Sys = /etc/codex/config.toml; MgdDef = managed_config.toml / MDM config_toml_base64 (overrides CLI); Req = requirements (cloud, MDM, /etc/codex/requirements.toml) as constraints.

| Setting class | CLI | Proj | Prof | User | CloudDef | Sys | MgdDef | Req (constrain) | Resolved view |
|---|---|---|---|---|---|---|---|---|---|
| approval_policy | yes (-a, -c) | yes | yes | yes | yes | yes | yes (legacy single-value req) | allowed_approval_policies | /debug-config (per layer) |
| sandbox_mode | yes (-c, flags) | yes | yes | yes | yes | yes | yes | allowed_sandbox_modes | /debug-config |
| model | yes (--model) | yes | yes | yes | yes | yes | yes | not seen | /debug-config, /status (unverified) |
| model_provider / model_providers | yes | NO (ignored) | yes | yes | likely | yes | likely | not seen | /debug-config, startup warning |
| context / auto-compact | yes | yes | yes | yes | yes | yes | yes | not seen | /debug-config |
| AGENTS.md instructions | --cd changes walk | files root->cwd | n/a | ~/.codex AGENTS(.override).md | n/a | n/a | n/a | n/a | none; ask agent, session jsonl |
| project_doc_max_bytes / fallback names | yes | yes (not ignored) | yes | yes (doc example) | yes | yes | yes | no | /debug-config |
| skills | n/a | .agents/skills cwd->root | n/a | ~/.agents/skills, [[skills.config]] | n/a | /etc/codex/skills | n/a | features may pin | none found |
| mcp_servers | yes | yes (not on ignore list) | yes | yes | likely | yes | yes | allowlist (name+identity) | codex mcp list (not verified this run), /debug-config |

| project trust | n/a | n/a | n/a | [projects."path"] trust_level | n/a | n/a | n/a | n/a | startup 'disabled' warning |
