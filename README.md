# usher

Front-of-house for the AI tooling fleet.

Usher helps people get seated — install and configure AI tools
(Claude Code, marvel, codex, …), attach supporting services, start
with correct settings, stay updated — and keeps the house running by
reporting harness configuration and usage to a cloud service that
turns reports into compliance checks and recommendations.

Wakatime + enterprise configuration management, for AI harnesses.
Invisible after install.

**Status:** design phase — see [charter.md](charter.md). Private for now.

Part of the [aae-orc](https://github.com/ArcavenAE/aae-orc) fleet.
